# Barka

متجر إلكتروني جديد مبني من البداية باستخدام Flask لعرض المنتجات والأسعار باللغة العربية، مع سلة شراء، حفظ طلبات، ولوحة إدارة.

## التشغيل

```powershell
cd d:\GOLD PRO\barka
python -m pip install -r requirements.txt
python app.py
```

بعد التشغيل افتح:

`http://127.0.0.1:5051`

## لوحة الإدارة

- رابط الدخول: `/admin/login`
- اسم المستخدم الافتراضي: `admin`
- كلمة المرور الافتراضية: `admin123`

يمكن تغييرها عبر متغيرات البيئة التالية:

- `BARKA_ADMIN_USERNAME`
- `BARKA_ADMIN_PASSWORD`
- `BARKA_SECRET_KEY`

## المحتوى الحالي

- صفحة رئيسية للمتجر
- بطاقات منتجات مع السعر الحالي والسابق
- صفحة تفاصيل لكل منتج
- واجهة API على `/api/products`
- سلة شراء مرتبطة بالجلسة
- نموذج إتمام طلب يحفظ البيانات في SQLite
- لوحة إدارة لإضافة وتعديل وحذف المنتجات
- إدارة حالات الطلبات من لوحة التحكم

## التطوير لاحقًا

- إضافة صور حقيقية للمنتجات
- ربط بوابة دفع
- إضافة تقارير مبيعات وإحصاءات للإدارة
